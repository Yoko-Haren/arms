How it works

From class record to report, in four steps.

Grades follow one clear path every grading period, so everyone knows where each class stands.

  1. 01

    Upload

    The teacher uploads the class record for each class and quarter.

  2. 02

    Check

    ARMS recomputes every grade from the scores and flags anything that looks off.

  3. 03

    Validate

    The registrar validates the class, or returns it to the teacher with a note.

  4. 04

    Report

    The school head sees results by subject and section, ready to export.

Role-based access

Teachers, the registrar, school heads and administrators each see only their own work.

Deadlines built in
