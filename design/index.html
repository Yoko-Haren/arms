Doing it by hand

  1. Flows: press Copy for Figma on a flow, click the Figma canvas and press Ctrl+V; it arrives as editable shapes and text. Download SVG gives a file to drag in, and Copy Mermaid the source for FigJam's Mermaid tools.
  2. Screens: open a screen and capture it with a Figma import plugin such as html.to.design, or take a full-page screenshot and place it in a 1440-wide frame.
  3. Styles: import design/tokens.json with a tokens plugin to create the colour and text styles shown under Foundations.
  4. After the system changes: run python manage.py export_screens to refresh every screen, then design/tools/figma/convert.py to rebuild the Figma layers.
